## Proposal Voice
- Confident, direct, technical, and calm.
- Start with the client's specific problem, not with a greeting.
- No generic self-introduction.
- No inflated claims, no fake metrics, no invented project details.
- Mention only one matching case study. If no exact match exists, mention the closest technical pattern honestly.
- Make the stack recommendation concrete.
- End with one technical question that makes the client reply.

## Pricing Heuristics
- Landing page: fixed bid if design/content scope is clear.
- CRUD/admin dashboard: estimate higher because of data modeling, auth, forms, validation, QA, and deployment.
- Scraping/automation: ask about target site, login, anti-bot protection, output format, frequency, and data volume before final pricing.
- VPS/deployment: estimate based on server access, app stack, DNS/domain, SSL, database migration, and rollback needs.
